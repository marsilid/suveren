# План Suveren

Порядок такой: сначала инструмент не должен сам быть дырой, потом он не должен врать, и только
потом обрастает новыми возможностями.

Обозначения: ✅ сделано, ⏳ в работе, ⬜ не начато.

## 0 — уборка ✅

- Рабочая папка переведена на `main`, слитые ветки удалены, ночной прогон настроен.

## 1.1.1 — безопасность самого инструмента ✅

Выпущено 31.10.2026: exe в Releases, пакет на PyPI.

- Ни один запрос не уходит во внутреннюю сеть, это проверяется на каждом шаге перенаправления.
- Ответ сайта ограничен 10 МБ, gzip-бомба не проходит.
- Браузер не скачивает файлы.
- Exe и Docker-образ собираются из зависимостей, закреплённых по хешам.
- Отчёт с плагинами помечен.
- У проверок блокировок указан настоящий источник: antifilter и дата выгрузки.
- SECURITY.md переписан.

## 1.1.2 — честность ⏳

Ветка `1.1.2-honesty`.

### Хвосты 1.1.1 ✅

- Браузер ходит в сеть через встроенный прокси.
- TLS и WHOIS идут только на публичные адреса.
- В SECURITY.md исправлен текст про `HTTPS_PROXY`.

### Исправления по ревью, по порядку

- ✅ ИНН в формате «ИНН/КПП»; ИНН банка больше не принимается за ИНН владельца.
- ✅ PD-008: «нет HTTPS» ставится, только когда HTTPS действительно нет.
- ✅ Поддомены: пустой ответ crt.sh и сбой DNS больше не дают ложных выводов.
- ⏳ Надёжность: плагины, ошибки Playwright, лимит распаковки gzip.
- ⬜ Точность: уязвимости moment.js, CSP с `default-src 'self'`, сроки сертификатов.
- ⬜ Мелкие замечания: DMARC, cookies, SARIF, MTA-STS и другие.

### Остальное

- ⬜ Две метки у каждой проверки:
  - что она делает с сайтом: только смотрит, что-то меняет или прощупывает;
  - чем рискует тот, кто запускает, например выполняется ли JavaScript сайта.

  По этим меткам переписать README.
- ⬜ Источник и дата у каждого реестра.
- ⬜ Файл исключений `.suveren-ignore`: в каждой записи причина, автор и срок действия.
- ⬜ Проверка разборщиков SPF, DMARC, CSP, cookies и карты сайта на случайных данных.

## 1.2 — польза ⬜

- Российские реестры контрагентов: Росфинмониторинг, иноагенты, дисквалифицированные лица,
  недостоверность и массовый адрес ФНС, Федресурс, РНП. Нужен российский IP.
- Отчёт на одну страницу для директора.

  - длина ключа DKIM;

  - DNSSEC;
  - висящие A-записи на облачные адреса.

- Удобство: разделы в справке, сообщения на русском, быстрый и глубокий режимы в меню, PDF для
  проверки компании.
