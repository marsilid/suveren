# Проверки Suveren

Файл создаётся командой `suveren checks --markdown > docs/checks.md` из каталога `src/suveren/catalog.py`. ID проверки не меняется между версиями: на него можно ссылаться в отчётах, задачах и правилах CI (`suveren scan сайт --checks ID`).

Статусы: **проблема** — нарушение или уязвимость найдены; **внимание** — возможная проблема, нужна ручная проверка; **не проверено** — данных не хватило (это лучше ложной тревоги); **в порядке**.

## Иностранные зависимости

Находки об иностранных сервисах имеют ID по категории: `SUV-DEP-DNS`, `SUV-DEP-HOSTING`, `SUV-DEP-MAIL`, `SUV-DEP-CDN`, `SUV-DEP-ANALYTICS` и т. д. (`SUV-DEP-` и название категории). Они есть в JSON (`findings[].id`) и SARIF.
