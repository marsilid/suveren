# Проверка сайта на 152-ФЗ

Сайт обрабатывает персональные данные, если на нём есть формы, счётчики посещений, онлайн-чат
или вход в личный кабинет. В этом случае на него распространяется Федеральный закон
№ 152-ФЗ «О персональных данных».

## Требования к сайту

| Требование | Норма | Ручная проверка |
|---|---|---|
| Политика обработки персональных данных опубликована на сайте | 152-ФЗ, ст. 18.1 | ссылка на политику в подвале сайта и у форм |
| Политика содержит цели, состав данных, сроки, права субъекта | 152-ФЗ, ст. 18.1; рекомендации Роскомнадзора | сравнение текста политики с фактической работой сайта |
| Согласие на обработку запрашивается в формах, собирающих данные | 152-ФЗ, ст. 9 | все формы сайта: заявка, обратный звонок, подписка, регистрация |
| Согласие оформлено отдельным документом | 152-ФЗ, ст. 9 ч. 1, с 01.09.2025 | ссылка у отметки согласия ведёт на отдельный документ, а не на оферту или политику |
| Посетитель уведомлён о cookies при использовании метрики и рекламы | позиция Роскомнадзора | наличие уведомления при первом посещении |
| Роскомнадзор уведомлён о трансграничной передаче | 152-ФЗ, ст. 12, с 01.03.2023 | наличие на сайте Google Analytics, Meta Pixel, иностранных чатов и виджетов |
| Данные граждан РФ записываются и хранятся в базах в России | 152-ФЗ, ст. 18 ч. 5 | расположение сервера сайта и CRM |
| Оператор есть в реестре операторов персональных данных | 152-ФЗ, ст. 22 | поиск по ИНН на pd.rkn.gov.ru |
| Данные передаются по защищённому соединению | 152-ФЗ, ст. 19 | сайт работает по HTTPS |

## Штрафы

КоАП, ст. 13.11, для юридического лица:

| Нарушение | Часть | Штраф |
|---|---|---|
| Политика обработки не опубликована | ч. 3 | 30–60 тыс. ₽ |
| Обработка без необходимого согласия | ч. 1 | 150–300 тыс. ₽; повторно 300–500 тыс. ₽ |
| Нет уведомления об обработке персональных данных | ч. 10 | 100–300 тыс. ₽ |
| Данные граждан РФ хранятся не в России | ч. 8 | 1–6 млн ₽; повторно 6–18 млн ₽ |

Суммы сверены с редакцией КоАП от 04.08.2026. Размер штрафа назначает суд или Роскомнадзор с
учётом обстоятельств дела.

## Проверка с помощью Suveren

```bash
pip install "suveren[browser]"
suveren scan example.ru --checks pd --browser
```

`--checks pd` ограничивает проверку разделом персональных данных. `--browser` открывает
страницы в браузере, чтобы учесть счётчики и виджеты, которые загружаются скриптами. На
Windows те же проверки доступны в меню
[Suveren.exe](https://github.com/marsilid/suveren/releases/latest).

Что выполняется:

- поиск политики на главной и внутренних страницах, проверка её разделов;
- анализ форм: какие поля собирают персональные данные и есть ли согласие;
- определение сервисов, получающих данные посетителя, и стран их расположения;
- определение расположения сервера сайта по базе DB-IP;
- сопоставление политики с фактической работой сайта: оператор, данные из форм, cookies,
  третьи лица, страны;
- поиск оператора в реестре Роскомнадзора;
- расчёт суммы возможных штрафов.

Для каждой находки отчёт приводит доказательство, статью закона со ссылкой на текст и
рекомендацию. Перечень проверок `SUV-PD-*`:
[Проверки, раздел «Персональные данные»](checks.md#персональные-данные-152-фз).

!!! note "Ограничения"
    Проверка выполняется снаружи. Договоры с обработчиками, фактическое место хранения CRM и
    поданные в Роскомнадзор уведомления Suveren не видит. Отчёт не является юридическим
    заключением.
