# Changelog

## 1.0.0 — 2026-10-06

Первый публичный выпуск.

### Иностранные зависимости (`scan`)

- Проверка DNS, почты, хостинга, CDN, регистратора, доменной зоны, SSL-сертификата и скриптов
  на странице по базе из 150+ иностранных и российских сервисов.
- Оценка независимости от A до F, рекомендации с российскими альтернативами, учёт резервирования.
- Пометки о сервисах, заблокированных или не работающих в России, и о скомпрометированном
  polyfill.io.
- Сравнение двух проверок командой `diff`, `--fail-under` для CI.

### 152-ФЗ и блокировки (входят в `scan`, отключаются `--quick`)

- Политика обработки ПДн и её содержание, согласие в формах, уведомление о cookies,
  трансграничная передача, локализация данных, HTTPS.
- Поиск ИНН на сайте и странице контактов, проверка по реестру операторов ПДн Роскомнадзора.
- Проверка домена и IP-адресов по реестру блокировок Роскомнадзора.

### Проверка компании (`company`)

- Данные ЕГРЮЛ/ЕГРИП по ИНН, ОГРН или домену: статус, возраст, руководитель.
- Скрининг компании и руководителя по санкционным спискам США, ЕС и Великобритании с учётом
  транслитерации.
- Сверка ИНН на сайте с владельцем домена в WHOIS.
- Команда `update` для обновления списков; кэш на сутки.

### Прочее

- HTML- и JSON-отчёты, тёмная и светлая тема.
- `Suveren.bat` — меню для запуска на Windows без командной строки.
