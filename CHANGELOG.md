# Changelog

## 0.1.0 — 2026-10-06

Первый выпуск.

- Команда `scan`: зависимости от иностранных DNS, почты, хостинга, CDN, регистратора,
  доменной зоны, SSL-сертификата и скриптов на странице.
- Оценка независимости от A до F, рекомендации с российскими альтернативами.
- Пометки о сервисах, заблокированных или не работающих в России.
- HTML- и JSON-отчёты, сравнение двух отчётов командой `diff`.
- База из 150+ сервисов, команда `services` для её просмотра.
- `Suveren.bat` — меню для запуска на Windows без командной строки.
