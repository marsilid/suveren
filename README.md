# Suveren

**Насколько ваш сайт зависит от иностранных сервисов и что будет, если их отключат.**

[![CI](https://github.com/marsilid/suveren/actions/workflows/ci.yml/badge.svg)](https://github.com/marsilid/suveren/actions/workflows/ci.yml)
![Python](https://img.shields.io/badge/python-3.10%E2%80%933.14-blue)
![License](https://img.shields.io/badge/license-MIT-green)

[English version](README.en.md)

</div>

Suveren проверяет домен и находит всё, что держится на иностранной инфраструктуре: DNS, почту,
хостинг, CDN, регистратора, SSL-сертификат, а также скрипты и виджеты на сайте. Для каждой
зависимости он объясняет, чем она грозит, и предлагает российскую замену. В конце ставит оценку
независимости от **A** до **F**.

Кому пригодится:

- владельцам бизнеса и ИТ-директорам — понять, что отвалится при следующей волне санкций;
- веб-студиям — проверить сайты клиентов и показать понятный отчёт;
- юристам и ответственным за 152-ФЗ — найти трансграничную передачу данных посетителей.

![Вывод в терминале](docs/demo.svg)

## Что проверяется

| Что | Как определяется | Чем грозит |
|---|---|---|
| DNS-серверы | NS-записи и сеть их IP-адресов | блокировка аккаунта кладёт сайт и почту сразу |
| Почта | MX-записи | потеря входящих писем и архива переписки |
| Хостинг | IP сайта → сеть (ASN) и страна её владельца | удаление аккаунта вместе с данными, 152-ФЗ ст. 18 |
| CDN и анти-DDoS | IP сайта | недоступность и замедление для пользователей из РФ |
| Регистратор | RDAP / WHOIS | отказ в продлении домена |
| Доменная зона | TLD | санкционные требования иностранного реестра |
| SSL-сертификат | TLS-рукопожатие | отзыв сертификата иностранным УЦ |
| Скрипты и виджеты | код главной страницы | аналитика, капча, шрифты, чаты, карты, видео, оплата, вход через соцсети |

Отдельно отмечаются сервисы, которые в России заблокированы или не работают: Meta (Facebook,
Instagram), LinkedIn, X (Twitter), YouTube, Google Ads, а также скомпрометированный polyfill.io.

В базе **150+ сервисов**: и иностранных, и российских. Российские тоже распознаются, чтобы
в отчёте была видна полная картина. Посмотреть базу: `suveren services`.

## Установка

Нужен Python 3.10 или новее.

```bash
pip install git+https://github.com/marsilid/suveren.git
```

На Windows можно просто скачать репозиторий и запустить `Suveren.bat`. При первом запуске
он сам всё установит и откроет меню.

## Использование

```bash
suveren scan example.ru
```

Отчёт сохраняется в `reports/` и открывается в браузере.

![HTML-отчёт](docs/report-screenshot.png)

Полезные параметры:

```bash
suveren scan example.ru --json before.json      # сохранить результат для сравнения
suveren scan example.ru --no-open               # не открывать браузер
suveren scan example.ru --fail-under C          # код выхода 3, если оценка хуже C (для CI)
suveren scan example.ru --dns doh               # DNS через DNS-over-HTTPS
```

### Отслеживание импортозамещения

Сохраните JSON до и после переезда и сравните:

```bash
suveren scan example.ru --json before.json
# ... переехали на российские сервисы ...
suveren scan example.ru --json after.json
suveren diff before.json after.json
```

Пример вывода:

```text
example.ru: независимость D → A, 52 → 96 из 100

  − убран    DNS-серверы: Cloudflare
  − убран    Почта: Google Workspace
  + добавлен DNS-серверы: Selectel
  + добавлен Почта: Яндекс 360
```

## Как считается оценка

Каждая категория с иностранной зависимостью даёт один риск, и за него снимаются баллы:
высокий −20, средний −10, низкий −4. Оценка: A от 90, B от 75, C от 60, D от 40, ниже — F.

Если в категории есть и иностранный, и российский сервер (например, резервный NS у российского
провайдера), риск понижается на одну ступень: это реальное резервирование.

Страной сервиса считается юрисдикция компании-владельца, а не место дата-центра: санкции
применяются к компании.

## Ограничения

- Скрипты ищутся только на главной странице. Что подключается на других страницах или внутри
  JS-бандлов, может не попасть в отчёт.
- Если сайт за CDN, настоящий хостинг скрыт, и Suveren об этом предупреждает.
- Проверка пассивная: публичные DNS-записи, WHOIS, один TLS-запрос и одна загрузка главной
  страницы. Никакого сканирования портов и подбора.
- Отчёт помогает расставить приоритеты и не является юридическим заключением.

## Как добавить сервис в базу

База находится в [`src/suveren/services.py`](src/suveren/services.py). Каждый сервис описывается
одной записью:

```python
Service(
    "Hetzner",               # название
    "DE",                    # страна компании (ISO 3166)
    ns=("hetzner.com",),     # суффиксы NS-серверов
    mx=("your-server.de",),  # суффиксы MX-серверов
    asn=(24940,),            # номера автономных систем
    as_names=("hetzner",),   # или фрагменты названия сети
)
```

Для сервисов, которые подключаются на странице, задаётся категория и регулярные выражения:

```python
Service("Яндекс Метрика", "RU", c.ANALYTICS, page=(r"mc\.yandex\.(?:ru|com)",)),
```

Добавьте тест в `tests/test_services.py` и откройте pull request.
